\# Lab 4: LLM Decision Support System



A decision support system for microfinance loan officers using Large Language Models (LLMs).



\## Overview



This system processes loan application letters and provides:

\- \*\*Summarization\*\*: 3-4 sentence factual briefs

\- \*\*Structured Extraction\*\*: JSON data for downstream systems

\- \*\*Decision Support\*\*: Balanced briefs with strengths, risks, and suggested actions
